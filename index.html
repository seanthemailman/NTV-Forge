Build a channel from a direct stream, Twitch, YouTube video, livestream, or YouTube playlist, then connect it to NostalgiaTV. Follow these steps in order. Your channels are saved on this PC. Fresh installations start empty; restore a JSON backup to bring back your lineup.

01

Add a video source

First, tell Link Forge where the video lives. You can reuse one source for multiple channels.

An internal name to help you recognize this source when assigning it to a channel. Example: “Vintage Commercials — YouTube playlist.” Viewers see the channel name, not this label. Paste the full HTTP(S) link to a Twitch channel, individual YouTube video, YouTube livestream, YouTube playlist, or direct MP4/TS/HLS stream. YouTube and Twitch need the installed extraction tools; Link Forge resolves and relays them when NTV tunes in.
Detected type: Enter a URL to classify it.

02

Create a channel

Name your channel and select a source saved in Step 1.

The on-screen station name that appears in the NostalgiaTV channel list and M3U guide, e.g. “Vintage Commercial Breaks.” Optional notes about the channel’s content or purpose. Saved in the project backup; the current M3U export does not include this description. Choose which saved source this station plays. The channel will be omitted from the M3U if the source is missing or its URL format is unsupported.
03

Review your lineup

Review your channels and their assigned sources before connecting to NTV. Source availability is checked automatically. You can also refresh an individual source.

04

Connect to NostalgiaTV

Keep the Link Forge launcher window running. NTV reads these links from your PC over the local network.

● Checking local server…
Choose the address that NTV can reach. For your home network this will usually start with 192.168. If you have VPNs or multiple adapters, test the choices. Copy this into NTV → Configure → HDHR / XMLTV Sources → Add Source → M3U URL. Do not paste it into a single channel's Stream URL field.

05

Save, back up & export

Changes save to the Link Forge server automatically. Back up the project before installing a newer version. File exports are optional; NTV normally uses the live URLs in Step 4.
