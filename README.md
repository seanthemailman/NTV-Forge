# NTV-Forge
Portable Windows tools for creating and managing NostalgiaTV channels
# 📼 NTV Forge 1.0 Beta
**Portable Windows Edition (64-bit)**

NTV Forge combines two tools designed to expand your NostalgiaTV experience:

- **Channel Forge:** Connect to Plex or Jellyfin to browse your media libraries, organize titles into channels, and import/export NostalgiaTV-compatible CSV files.
- **Link Forge:** Create live TV channels from supported YouTube and Twitch links using M3U playlists and XMLTV guides.

## 📦 Installation

1. Download `NTV-Forge-v1.0-Beta-Windows-x64.zip` from the GitHub Releases section.
2. Extract the entire ZIP into a folder of your choice.
3. Open the extracted folder and double-click **NTV Forge.exe**.
4. The application opens in your default web browser and continues running in the Windows system tray.
5. Select **Channel Forge** or **Link Forge** to begin creating channels.

## 🔧 Using NTV Forge with NostalgiaTV

**Channel Forge:** Export your completed channel CSV and import it into NostalgiaTV.

**Link Forge:** Add your YouTube or Twitch sources, create channels, and copy the generated M3U and XMLTV URLs into NostalgiaTV's live TV settings.

Keep NTV Forge running while using Link Forge channels.

## ✅ Requirements

- Windows 10/11 (64-bit)
- Network connection for streaming and media server access
- No Python installation required
- FFmpeg, yt-dlp, Streamlink, and Deno are included
